# Personal Project:GPT-style Language Model Implementation
·  Implemented a GPT-2-style decoder-only Transformer architecture, including causal multi-head self-attention, feed-forward layers, layer normalization, and GELU activations.
·  Implemented tokenization and data-loading components, including byte-pair encoding and a sliding-window data loader.
·  Implemented text-generation routines with greedy decoding and temperature-controlled sampling; current work focuses on architecture implementation, with training and fine-tuning not yet performed.
